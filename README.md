¡Bienvenido/a a **Fundamentos de Ciberseguridad**! Este repositorio está diseñado como un compendio práctico de herramientas, scripts, guías y recursos enfocados en la auditoría de seguridad y el **Pentesting**.

El objetivo principal es proporcionar un punto de acceso rápido a utilidades esenciales utilizadas en las distintas fases de un análisis de seguridad.

## Objetivos de Aprendizaje

- Aprender el uso práctico de las herramientas estándar de la industria.
- Documentar metodologías de hacking ético paso a paso.
- Disponer de un cheat sheet de consulta rápida para auditorías y laboratorios (CTFs).

## Fases del pentesting

| Fase | Descripción |
|------|-------------|
| [00 - Introducción](./00-Introduccion) | Conceptos y contexto de la ciberseguridad |
| [01 - Reconocimiento](./01-Reconocimiento) | Recopilación de información sobre el objetivo |
